# kailicao.github.io

The source of Kaili Cao's personal website, published by GitHub Pages at <https://kailicao.github.io/>. Kaili Cao is an Eric and Wendy Schmidt AI in Science Postdoctoral Fellow at the Michigan Institute for Data and AI in Society (MIDAS), University of Michigan.

Version 0.5 (October 2026) has a home page with news; About (with publications, presentations, software and a personal page); AI in science; research on images, cosmology and stars, with one page per topic; and opinions on teaching, research ethics and careers; more is coming. MapHub, the MIDAS arXiv Preprint Hub, is at <https://kailicao.github.io/maphub-public/>.

The site is plain HTML and CSS, with no build step: edit the pages directly.

| Path | Contents |
| --- | --- |
| `index.html`, `about.html`, `ai.html`, `images.html`, `cosmology.html`, `stars.html`, `opinions.html` | The main pages: home, about, AI in science, the three research areas, opinions |
| `publications.html`, `presentations.html`, `software.html`, `about/` | Under About: publications, presentations, software, personal |
| `research/` | One page per research topic (image reconstruction and analysis, cosmological inference and simulations, stellar modeling, asteroseismology) |
| `opinions/` | Teaching, research ethics, and career notes |
| `research.html`, `research/ai-in-science.html`, `resources.html`, `resources/` | Redirects from addresses published in version 0.4 |
| `presentations/` | Slides as PDF files (third-party images blurred and described) |
| `assets/` | The stylesheet and the icons |
| `cv/` | The CV: LaTeX source (moderncv) and `Kaili_Cao_CV.pdf`, the copy the site links to; run `latexmk` in `cv/` to rebuild it |
