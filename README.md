# kailicao.github.io

The source of Kaili Cao's personal website, published by GitHub Pages at <https://kailicao.github.io/>. Kaili Cao is an Eric and Wendy Schmidt AI in Science Postdoctoral Fellow at the Michigan Institute for Data and AI in Society (MIDAS), University of Michigan.

Version 0.4 (October 2026) has the home page, an about page, research (one page per track, publications and presentations), and resources (software, and notes for students); more is coming. MapHub, the MIDAS arXiv Preprint Hub, is at <https://kailicao.github.io/maphub-public/>.

The site is plain HTML and CSS, with no build step: edit the pages directly.

| Path | Contents |
| --- | --- |
| `index.html`, `about.html`, `research.html`, `publications.html`, `presentations.html`, `resources.html` | The main pages |
| `research/` | One page per research track |
| `resources/` | Software, and notes for students |
| `assets/` | The stylesheet and the icons |
| `cv/` | The CV: LaTeX source (moderncv) and `Kaili_Cao_CV.pdf`, the copy the site links to; run `latexmk` in `cv/` to rebuild it |

Contact: <kailicao@umich.edu>
