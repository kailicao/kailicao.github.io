Teaching and mentoring

  • I created and taught an online Python tutorial (2022–2023): 46 students in four cohorts. I gave the lectures, designed the exercises and mentored students' personal projects.
  • In the Roman HLIS Cosmology Project Infrastructure Team, I help new graduate students and undergraduates get started with the PyIMCOM code, including a hack session in 2025.
  • Teaching associate (grader), graduate quantum mechanics (Physics 7501 and 7502), The Ohio State University, 2021–2023.
  • Tutoring in college mathematics and physics and in French phonology, and pro bono help with graduate school applications (2022–2024).

When I teach, I try to remember what it was like not to know, and I ask questions that let students make the connections themselves. Setting reasonable expectations matters too: frustration is often the biggest barrier for beginners in computational research. My aim is for students to move from using code to building their own research tools, and to use AI to reach better answers than AI alone would give.

Skills and software

  • Programming: Python (my main language; object-oriented, high-performance code with NumPy and Numba), C/C++, Fortran, Shell and Perl, Mathematica. Git and GitHub for all my projects.
