Image Reconstruction

Reconstructing well-sampled images with a controlled point spread function from a telescope's undersampled exposures, for the Nancy Grace Roman Space Telescope and beyond.

In brief

The Nancy Grace Roman Space Telescope will observe from space, where its point spread function (PSF) is stable and sharp, limited only by diffraction. That is both a blessing and a curse. Roman's pixels, 0.11 arcseconds across, are about as large as the PSF itself, but fully sampling an image would need pixels about half that size. So native Roman images are undersampled, and the best current methods for measuring galaxy shapes need well-sampled images.

Shapes matter because the main science driver of Roman's High Latitude Imaging Survey is weak gravitational lensing. Matter in the foreground distorts the images of distant galaxies, but only at the percent level, while the intrinsic shapes of galaxies differ by about 30%. To recover the lost detail, Roman shifts slightly between exposures (dithering), and the exposures are later combined into well-sampled images. Each output pixel is a weighted sum of input pixels, and the choice of weights also decides the output PSF. In simulations of Roman's survey pattern, Drizzle, the traditional method for space telescopes, turns the image of a star into a hexagon. IMCOM chooses the weights so that the output PSF is as close as possible to a target that the user specifies, which is what weak lensing needs.

I think of this software as a scientific instrument: how it is designed, tested and calibrated decides what the data can tell us, as much as the telescope itself does.

What I have done

I led the refactoring of IMCOM into PyIMCOM: object-oriented code with improved data structures and new linear algebra strategies, which reduced the computing cost by about an order of magnitude (Cao et al. 2025). I then tuned its hyperparameters, comparing 26 configurations in each of five bands on 12 criteria; wider Gaussian target PSFs, for example, led to better images (Cao et al. 2026). PyIMCOM produced the IMCOM coadds of OpenUniverse2024, a shared simulated sky for Roman and Rubin, and it is the platform for several team papers (see Image Analysis).

Even so, IMCOM is expensive: reconstructing one image from Roman's Wide Field Instrument takes about a day on a single CPU core. That is affordable for precision cosmology, but it keeps others from using it. A study in one dimension (Cao and Roman HLIS Cosmology PIT 2026) led me to a new algorithm for linear image reconstruction, first called Fast IMCOM. Since it does not necessarily combine images, I renamed it Effortless (EFFicient Optimal image ReconsTruction using LESS memory). Like IMCOM, it controls the PSFs of output images, but by avoiding IMCOM's most laborious calculations, it is tens of times faster and has a smaller memory footprint: the same image takes about half an hour. The idea is to treat the weights given to input pixels as samples of an underlying weight field, and to design that field directly.

I describe Effortless in two companion papers. In one, I present its mathematical formalism, software implementation and practical issues (Cao 2026b). Foremost, while the Nyquist–Shannon sampling theorem remains true, its conditions differ subtly but importantly from the problem in survey data processing, and the effects of finite sampling can be greatly reduced by a simple calibration after measurement. Imperfections from numerical artifacts, from the finite windows of input pixels, and from input pixels that are unavailable are understood and under control. In designing the software, I aimed for a clear object-oriented structure, an intuitive data model and a friendly interface, and its programming interface is general enough for uses beyond weak lensing and beyond Roman. The code is public on GitHub.

In the other, I apply Effortless to simulated Roman images (Cao 2026a). It makes PSFs uniform and regular across reconstructed images more efficiently than IMCOM, and it has the potential to control systematic errors better. For ideal point sources, a single image reconstructed by Effortless, combined with the calibration above, can give better measurements than a set of about six images coadded by IMCOM. Whether the calibration carries over to noisy galaxies, which is what weak lensing measures, is not yet clear. And although both algorithms were designed for weak lensing, Effortless can serve studies of both static features and dynamic aspects of the Universe: because it puts images taken at different times onto the same pixel grid and PSF, it can help time-domain astronomers compare them. Its efficiency and interpretability also open new possibilities for reducing measurement errors further.

Like IMCOM, Effortless assumes that the astrometry, flux calibration and PSF models it is given are correct. In reality, all of them have errors, which is one reason for the work ahead.

What comes next

Effortless is the one idea from my PhD that has started to flourish. Next come its applications, a more general understanding of PSF residuals, and models of the noise covariance in reconstructed images.
